# swiftUITemplate
Simple template for SwiftUI project

## Project Overview

A template project that uses Tuist for modular architecture, The Composable Architecture for unidirectional data flow, and SwiftUI for UI drawing

## Plugins

- ConfigPlugin
   - plugin for configuring Xcode project builds
   - Build configuration is used to separate deployment environment such as development, stage, and production
